# 딥러닝 기반 저등급 신경교종(LGG) 분할 모형

Kaggle LGG Segmentation 데이터셋을 이용한 뇌 MRI 종양 이진 분할 프로젝트입니다.

| 항목      | 내용                                                    |
| --------- | ------------------------------------------------------- |
| 데이터    | Kaggle LGG Segmentation (환자 110명 · 슬라이스 3,929장) |
| 모형      | U-Net (직접 구현) · 파라미터 863만                      |
| 검증      | 환자 단위 층화 5-Fold + 파일럿 전용 홀드아웃 16명       |
| 최종 모형 | M1 (BCE 단독) — 슬라이스 재현율 0.8781 · PR-AUC 0.8382  |
| 작성      | 이정우 · 윤동길 · 배지수                                |

## 5. 캐시에 관하여

반복 실행 시간을 줄이기 위해 일부 검증 결과를 `cache/` 폴더에 저장합니다.

| 대상                           | 절약     |
| ------------------------------ | -------- |
| 128px 소실 검증 (1,373장 전수) | 약 30초  |
| 슬라이스 분할 누수 재현        | 1초 미만 |

**설정이나 함수 코드가 바뀌면 해시가 달라져 자동으로 다시 계산**되므로
잘못된 결과가 재사용될 위험은 없습니다.

### 캐시를 사용하지 않으려면

셀 6 에서 다음을 변경한 뒤 실행하십시오.

```python
USE_CACHE = False
```

또는 `cache/` 폴더를 삭제하면 됩니다.

> **채점·검증 목적으로 실행하실 경우 `USE_CACHE = False` 로 두고
> 커널을 재시작한 뒤 전체를 실행하시기를 권장합니다.**

## 8. 문제 해결

| 증상                             | 원인            | 조치                                         |
| -------------------------------- | --------------- | -------------------------------------------- |
| `kaggle_3m 폴더를 못 찾았습니다` | 데이터 미배치   | 1-2 절 참고                                  |
| `ModuleNotFoundError`            | 라이브러리 누락 | 셀 2 가 안내하는 `pip install` 실행          |
| `CUDA out of memory`             | VRAM 부족       | 셀 6 의 `BATCH_SIZE` 를 8 또는 4 로 낮춤     |
| 한글이 네모로 표시됨             | 폰트 부재       | 그래프 가독성 문제이며 결과에는 영향 없음    |
| 실행이 지나치게 느림             | GPU 미인식      | 셀 2 의 `=== 3. GPU ===` 항목 확인           |
| `AssertionError`                 | 검증 실패       | 해당 셀의 메시지를 확인 — 데이터 손상 가능성 |
